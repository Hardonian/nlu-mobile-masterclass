# Commercialization Plan

## Packaging options

1. Free self-serve course for awareness and lead generation.
2. Paid facilitator kit with worksheets, answer key, and workshop license.
3. Enterprise cohort package with custom policy scenarios and reporting.
4. Advisory implementation package using the reference orchestration core.

## Validation sequence

- Interview five target buyers.
- Run one paid or strongly committed pilot.
- Measure completion, assessment accuracy, facilitator effort, and willingness to pay.
- Only then select pricing and account features.

## Commercial blockers

Pricing, procurement, legal terms, support SLAs, branding rights, customer data processing, and enterprise tenancy require external decisions and named owners.
