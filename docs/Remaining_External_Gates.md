# Remaining External Gates

These items require decisions, accounts, representative users, or operational authority outside the repository.

| Area | Gate | Required evidence |
| --- | --- | --- |
| Browser QA | Run Chromium/WebKit and assistive-technology tests | CI artifacts and accessibility report |
| Hosting | Enable HTTPS host, domain, monitoring, and rollback | Deployment URL, owner, rollback drill |
| Privacy | Approve progress/analytics collection and retention | Signed privacy review |
| Security | Approve CSP, threat model, dependencies, and integration boundary | Security ticket and expiry date |
| Product | Approve MVP, owner, pricing, and non-goals | Product decision record |
| Content | Approve vendor claims, policy scenarios, and review cadence | Content-owner register |
| Pilot | Run facilitator and learner pilots | Findings, metrics, and remediation log |
| Integrations | Configure real identity, domain, retrieval, CRM, and provider accounts | Environment evidence and contract tests |
| Localization | Approve locale, translation, evaluation, and support coverage | Locale release record |
| Enterprise | Approve tenancy, procurement, support SLA, and data-processing terms | Customer/security approval |
