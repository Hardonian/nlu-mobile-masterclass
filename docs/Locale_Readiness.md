# Locale Readiness

A locale is release-ready only when all of the following exist:

- Translated lesson content and UI labels.
- Locale-specific evaluation cases, including short/mobile wording and speech-like input.
- Reviewed accessibility and reading-level treatment.
- Localized dates, numbers, currency, policy references, and handoff expectations.
- Facilitator guidance and answer key.
- Named translation/content owner and review date.

Do not expose a locale based only on translated navigation or machine-translated strings.
